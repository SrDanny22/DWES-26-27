# Ejercicio 16. Por qué file_exists no reserva el nombre

`file_exists` solo dice si el archivo existe en el momento de la consulta. Entre esa comprobación y `move_uploaded_file`, otro proceso puede crear un archivo con el mismo nombre, y la comprobación anterior ya no sirve. Por eso el nombre se genera con 16 bytes aleatorios: así es prácticamente imposible que coincida.
