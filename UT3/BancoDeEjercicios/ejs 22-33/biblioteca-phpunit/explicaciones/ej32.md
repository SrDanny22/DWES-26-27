# Ejercicio 32. Regresión y selección de pruebas

Con la versión defectuosa de `requerido`, el caso `espacios` de `testTituloRequerido` falla, y también el de `tabulación`. La regla vuelve a pasar una vez corregida con `trim($valor) === ''`. El caso de espacios queda como prueba de regresión.

```bash
composer test -- --filter testTituloRequerido
```

```bash
composer test
```

Hay que distinguir dos resultados:
- **Fallo (`F`, *Failure*):** la aserción se ejecuta, pero obtiene un valor distinto del esperado (`Failed asserting that null is identical to 'Escribe el título.'`). El código se carga bien; lo que falla es el comportamiento.
- **Error (`E`, *Error*):** el test no llega a comprobar nada porque se produce una excepción, por ejemplo `Class "App\Service\Validatorr" not found`. Es un problema de carga o de nombre, no de la regla.
