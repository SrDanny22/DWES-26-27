# Ejercicio 33. Qué demuestra cada prueba

## Pruebas unitarias de la portada

`App\Service\PortadaValidator::validar(int $tamano, string $mime)` se prueba en `PortadaValidator33Test`. Cada caso cambia una sola condición respecto a uno válido: 1 byte, 2 MiB, 2 MiB + 1, `image/png` y `text/plain`.

## Comprobación de integración con el ejercicio 21

1. Arrancar el receptor desde `BancoDeEjercicios`:

```bash
php -S localhost:8000 -t ej21/public
```

2. Enviar un formulario multipart real con una imagen PNG:

```bash
curl -i -F "titulo=Dune" -F "paginas=412" -F "portada=@portada.png;type=image/png" http://localhost:8000/formulario-portada.php
```

3. Comprobar tres cosas:
   - que la respuesta tiene estado 200 y muestra la confirmación;
   - que en `ej21/storage/portadas` aparece un archivo nuevo con 32 caracteres hexadecimales y extensión `.png`;
   - que con `texto.jpg` o con páginas inválidas no aparece ningún archivo nuevo.

Crear un archivo temporal desde la terminal no demuestra lo mismo. `move_uploaded_file` solo acepta los archivos que PHP ha recibido en la subida HTTP de la petición actual. Un archivo creado a mano existe en disco, pero no está registrado como subido, así que la función devuelve `false` (se ve en `ej17/prueba-terminal.php`).

## Ejecutar no es comprobar

`Libro33Test` añade `assertFalse($libro->estaDisponible())` después de `prestar()`. Sin esa aserción, el test solo demostraría que la línea se ejecuta sin excepciones, y seguiría pasando aunque `prestar()` no cambiara nada.

## Cobertura

Para medirla hace falta que el PHP de la terminal tenga Xdebug o PCOV (`php -m`). En este equipo no hay ninguno de los dos instalado. El porcentaje solo indica qué líneas se han recorrido. No demuestra que se hayan comprobado los límites ni los resultados, porque una línea puede ejecutarse dentro de un test que no tiene ninguna aserción.
